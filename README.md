# OpBattle 🏆

Global Esports Tournament Platform

## Tech Stack
- **Frontend:** Next.js (Vercel)
- **Backend:** NestJS (Railway)
- **Database:** PostgreSQL (Neon)

## Features
- Player Verification via PUBG UID
- Team Management
- Tournament System
- Live Streams
- Wallet & Payments

## Setup
1. Clone repository
2. Backend: `cd backend && npm install && npm run start:dev`
3. Frontend: `cd frontend && npm install && npm run dev`
